This application uses FastAPI to allow clients to upload, organize or filter, and/or process movies. There are three main groups of modules: “data_pipeline”, which loads, processes, validates, and saves the data, “src”, which holds the models, storage, middleware, and cache, and “tests”, which holds the pytest fixtures and asserts. Upload, SQL storage, processing, and caching work together by affecting the dataframe and what is stored. Upload allows for the uploading of a csv, and SQL storage will save that data. Then, the data is processed, which impacts what data is saved, and caching saves previous requests and queries for future client requests. To start the API, use the command “python3 -m uvicorn main:app –reload”, and to run the tests, use the command “python3 -m pytest tests -v”. A sample processing request would be requiring all four columns (although only two for the numeric columns), and using duplicate removal, missing value handling, and outlier removal. This would return “rows_before”: 20, “rows_after”: 16, “rows_removed”: 4, “columns_before”: 4, “columns_after”: 4, and “columns_removed”: 0.
